# evertech-proposals

### 🇷🇺 Русский
Этот репозиторий создан для того, чтобы игроки игры **Evertech Sandbox** могли предлагать новые фичи.

**Как предложить фичу:**  
Создайте Issue, но перед этим убедитесь, что никто ещё не предлагал эту идею.

---

### 🇬🇧 English
This repository was created so that players of **Evertech Sandbox** can suggest new features.

**How to suggest a feature:**  
Create an Issue, but first make sure that no one has suggested this idea before.

---

### 🇮🇩 Bahasa Indonesia
Repositori ini dibuat agar pemain game **Evertech Sandbox** dapat mengusulkan fitur-fitur baru.

**Cara mengusulkan fitur:**  
Buat Issue, tetapi sebelumnya pastikan bahwa tidak ada yang pernah mengusulkan ide ini sebelumnya.
